# Verão no Azul

App de planejamento financeiro de verão com visual Liquid Glass.

- Lista de gastos do verão com categoria e prioridade (essencial, quero, talvez)
- Simulador de trabalho: diária fixa + extra por entrega − custo por dia
- Período de trabalho com data de começo e data limite, e escolha dos dias da semana
- Poupança com depósito mensal e rendimento (CDB, poupança ou dinheiro em casa)
- Gráfico do dinheiro acumulado, tabela mês a mês, cenários de 3 a 7 dias por semana e projeção da poupança
- Recomendações com dados públicos de 2026 (salário mínimo, Selic, taxa mínima do iFood)

É um único arquivo `index.html`, sem build. Abra no navegador ou acesse pelo GitHub Pages.
Os dados ficam salvos no navegador (localStorage).

Estimativas para planejamento, não consultoria financeira.
